# Team Roles & Detailed Responsibilities

---

### 1. AI/ML Engineer
**Focus:** Forecasting, uncertainty, risk, anomaly detection

**Responsibilities:**
- Build short-term Price Forecast model
- Calculate Confidence score (High / Medium / Low)
- Create basic Risk Score logic
- Simple anomaly detection in price data
- Prepare basic explainability for forecasts

**Priority Tasks:**
- Price Forecast + Confidence
- Support Risk logic for recommendations

---

### 2. Optimization & Decision Engine Engineer
**Focus:** Decision logic

**Responsibilities:**
- Build Sale Window Recommendation logic
- Implement Net Realisation calculation
- Create basic What-If Simulator logic
- Design simple rule-based decision engine
- Prepare for future Sell/Store/Split logic

**Priority Tasks:**
- Sale Window Recommendation
- Net Realisation Calculator
- Basic What-If logic

---

### 3. Backend Engineer
**Focus:** APIs & Business Logic

**Responsibilities:**
- Develop Node.js / Express APIs
- Implement Authentication (Farmer / Buyer login)
- Create Crop Lot APIs (Create, Read, Update)
- Build Market Intelligence APIs
- Build Recommendation & Net Realisation APIs
- Handle business logic and connect with AI services

**Priority Tasks:**
- Auth APIs
- Crop Lot CRUD
- Market Intelligence APIs
- Recommendation APIs

---

### 4. Database & Data Engineer
**Focus:** Data layer

**Responsibilities:**
- Design PostgreSQL schema
- Create tables for users, crop_lots, market_prices, recommendations
- Build market data pipeline (AGMARKNET / data.gov.in)
- Store historical price data
- Handle data cleaning and basic validation

**Priority Tasks:**
- Complete database schema
- Market price data ingestion
- Crop lot & user data storage

---

### 5. Frontend Engineer
**Focus:** User Interfaces

**Responsibilities:**
- Build Farmer Portal (main focus)
- Create Dashboard with charts
- Build Crop Lot creation form
- Display Market Intelligence, Forecast, Recommendations
- Show Net Realisation clearly
- Create basic Buyer list page
- Make UI clean and demo-ready

**Priority Tasks:**
- Farmer Dashboard
- Market Intelligence screens
- Recommendation + Net Realisation UI
- Crop Lot form
- Basic Buyer view

---

### 6. Integration & DevOps Engineer
**Focus:** Connection & Deployment

**Responsibilities:**
- Connect Frontend ↔ Backend ↔ AI/Decision services
- Setup environment variables
- Help with Docker (optional)
- Integrate external data sources
- Make the full system run end-to-end
- Prepare basic deployment for demo

**Priority Tasks:**
- Full system integration
- Environment setup
- Demo-ready deployment
